⚙️ Parcours C++

La puissance du C, plus l'orienté objet, les templates et la STL : performance et abstraction réunies.

Toutes les formations de la pile C++, dans l'ordre conseillé — huit étapes, un fil rouge : la Ludothèque.

Légende : 🎯 cœur du bachelier (à faire en priorité) · 🧭 optionnel · plus tard (utile mais non essentiel dans l'immédiat). La durée indiquée par étape est une estimation à une leçon par jour.

🧠 Étape 1 — Les fondations : l'algorithmique · ~31 leçons

La logique avant le code, en pseudocode. Le socle de tout le parcours.

🧠

Algorithmique

La logique avant le code : variables, conditions, boucles, tableaux, fonctions, tris, récursivité, complexité.

31 jours · pseudocode · 🎯 cœur du bachelier

🧑‍💻 Étape 2 — Le langage C++ : deux approches · ~63 leçons

Le C++ peut s'apprendre de deux façons complémentaires. Choisis ton angle — ou suis les deux : le C++ moderne pour écrire du code sûr et expressif (STL, RAII, smart pointers), et le C++ bas niveau pour comprendre la mémoire et la continuité avec le C (pointeurs bruts, new/delete). Le front-end (HTML, CSS, JS) se suit en parallèle.

✨

C++ moderne

Le C++ tel qu'on l'écrit aujourd'hui (C++11/17) : classes et RAII, références et const, la STL (string, vector, map), templates génériques, smart pointers (unique_ptr), lambdas, exceptions et flux. Sûr, expressif, performant.

21 leçons · projet guidé : le gestionnaire de tâches · prérequis : cours Algorithmique · 🎯 cœur du bachelier

✍️ 21 exercices d'écriture intégrés aux leçons 🔩

C++ bas niveau (proche du C)

Comprendre la machine sous le C++ : pointeurs bruts, références, new / delete manuels, tableaux dynamiques, la règle de trois, la table des fonctions virtuelles, compilation séparée et chasse aux fuites (valgrind). La continuité avec le C, avant les abstractions.

21 leçons · projet guidé : le gestionnaire de tâches · prérequis : cours Algorithmique (le cours C aide) · 🎯 cœur du bachelier

✍️ 21 exercices d'écriture intégrés aux leçons 🎨

Le front-end : HTML, CSS, JavaScript

Tout ce que l'utilisateur voit : la structure sémantique (HTML), l'apparence responsive (CSS, flexbox, grid) et l'interactivité (JS, DOM, événements, fetch). Trois mini-projets assemblent le site de la Ludothèque.

21 leçons · fil conducteur : le site de la Ludothèque · prérequis : le cours Algorithmique aide · 🎯 cœur du bachelier

✍️ 21 exercices d'écriture intégrés aux leçons

🚀 Étape 3 — L'API et le rôle du C++ · ~21 leçons

Comme le C, le C++ n'a pas de framework web « batteries incluses » standard : il excelle au niveau système et applicatif (moteurs, jeux, calcul haute performance, interfaces Qt, embarqué). La conception d'API REST reste une culture transversale précieuse.

🔌

API REST

Le contrat entre un back-end et le reste du monde : HTTP, JSON, méthodes et codes de statut, conception des endpoints, pagination, erreurs propres, versions, OpenAPI, authentification (sessions, JWT), CORS et bonnes pratiques. Transversal à tous les langages.

21 leçons · fil rouge : l'API de la Ludothèque · prérequis : le langage C++, notions réseau · 🎯 cœur du bachelier

✍️ 21 exercices d'écriture intégrés aux leçons

🗄️ Étape 4 — Les bases de données · ~63 leçons

La conception (Merise), le langage SQL, puis le SGBD. En C++, on dialogue avec la base via le connecteur MySQL Connector/C++ (objets Connection, PreparedStatement, ResultSet).

🧩

Merise (MCD, MLD)

La méthode de conception : entités, associations, cardinalités, héritage, contraintes ; puis passage au modèle relationnel (tables, clés) et au physique.

21 leçons · projet guidé : la base de la Ludothèque · prérequis : aucun · 🎯 cœur du bachelier

✍️ 21 exercices d'écriture intégrés aux leçons 📐

UML (les 14 diagrammes)

Le pendant objet de Merise : cadrer le besoin (cas d'utilisation), décrire la structure (classes), le comportement (séquence, états) et l'architecture. Même fil rouge : la Ludothèque.

31 jours · fil rouge : la Ludothèque · prérequis : aucun (Merise aide) · 🧭 optionnel · recommandé si ton école enseigne l'analyse

SQL (le langage)

Créer, remplir et interroger une base : SELECT, WHERE, jointures, agrégats, GROUP BY, sous-requêtes, vues, index, transactions.

21 leçons · projet guidé : interroger la Ludothèque · prérequis : Merise · 🎯 cœur du bachelier

MySQL

Le SGBD open source le plus déployé : InnoDB, AUTO_INCREMENT, LIMIT/OFFSET, IFNULL, CTE et fenêtrage (MySQL 8), procédures (DELIMITER), triggers (NEW/OLD), transactions. Accessible en C++ via Connector/C++.

21 leçons · projet guidé : la Ludothèque en MySQL · prérequis : SQL · 🧭 optionnel · plus tard

🔗 Étape 5 — L'accès aux données

Le C++ n'a pas d'ORM standard imposé (des bibliothèques comme ODB existent). On écrit le plus souvent le SQL directement via MySQL Connector/C++ (requêtes préparées, curseurs de résultats) et on mappe les lignes dans des classes — une couche d'accès aux données objet, propre et testable.

🏗️ Étape 6 — Le projet full-stack (à la main) · ~21 leçons

La Ludothèque complète en C++, de la conception à la mise en service, sans outillage.

🏗️

Projet C++ · SQL · MySQL

Construire la Ludothèque de bout en bout en C++ : architecture en couches objet (UI → services → dépôt/DAO → MySQL), classes du domaine, accès MySQL via Connector/C++ avec requêtes préparées, services métier (louer/acheter en transaction), rôles et authentification, RAII et smart pointers, tests et mise en service.

21 leçons · fil rouge : la Ludothèque · prérequis : le langage C++, Merise, SQL, MySQL · 🎯 cœur du bachelier

🧰 Étape 7 — L'outillage professionnel · ~94 leçons

Les outils transverses appliqués à ton projet : versionner, tester, conteneuriser, automatiser, sécuriser. (Le cours Linux, dans la catégorie Système, est un compagnon idéal pour la pile C++.)

🌱

Git — les bases

Le contrôle de version de zéro : init, add, commit, status et diff, lire l'historique, .gitignore, annuler proprement (restore, revert), tags et versions, branches, puis GitHub (clone, push, pull).

10 leçons · à suivre dès le Niveau 2 · prérequis : un terminal · 🎯 cœur du bachelier

21 leçons · fil rouge : tester la Ludothèque · prérequis : un langage du Niveau 2 · 🧭 optionnel · plus tard

Conteneuriser la Ludothèque : images et Dockerfile (multi-stage, non-root), volumes, réseau, Compose (healthchecks, limites), registre et versions, observation, déploiement en production et retour arrière.

Automatiser la livraison : branches, pull requests et revue de code, pipeline GitHub Actions (build, tests, lint), protection de branche, versions semver, publication au registre, déploiement staging/production et rollback.

Sécurité applicative
