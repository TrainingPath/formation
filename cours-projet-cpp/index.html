🛠️ Avant de commencer : l'environnement

1. Compilateur et build. g++ (ou clang++) en C++17, et CMake pour organiser un vrai projet. Sous Debian/Ubuntu : sudo apt install build-essential cmake.

2. MySQL et le connecteur C++. Installe MySQL (ou MariaDB) et MySQL Connector/C++ (objets Connection, PreparedStatement, ResultSet). On l'utilise via ses en-têtes et on lie la bibliothèque à la compilation.

3. L'éditeur. VS Code (extension C/C++ + CMake Tools) ou CLion. Compile avec -Wall -Wextra et teste régulièrement avec -fsanitize=address : le C++ moderne (RAII, smart pointers) t'évite déjà la plupart des fuites.

💡 Ce projet assemble les briques déjà vues : on les fait travailler ensemble, en couches objet. Une leçon par jour, dans l'ordre.
