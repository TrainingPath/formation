🛠️ Avant de commencer : installe ton environnement

1. Le serveur MySQL (ou MariaDB, compatible). Installe MySQL Community Server, ou lance-le via Docker (docker run mysql), ou utilise un paquet tout-en-un (Laragon, XAMPP) qui l'inclut. Vérifie : mysql --version.

2. Un client. En graphique : MySQL Workbench (officiel) ou DBeaver (multi-SGBD). En ligne de commande : le client mysql, fourni avec le serveur.

3. Un éditeur pour les scripts. VS Code + l'extension « MySQL » (ou « SQLTools ») permet de se connecter et d'exécuter les requêtes sans quitter l'éditeur. On garde les scripts .sql versionnés.

💡 Conseil : installe MySQL (ou MariaDB) avec MySQL Workbench et exécute chaque requête. MySQL se comprend en interrogeant de vraies données.
