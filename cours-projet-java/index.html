🛠️ Avant de commencer : l'environnement du projet

1. Toute la pile Java est déjà installée. JDK 25 (cours Java) et Spring Boot via Spring Initializr (cours Spring). Génère un projet Maven/Gradle avec Spring Web, Spring Data JPA, le driver MySQL et Validation.

2. MySQL. Installe MySQL Community Server (ou via Docker, ou Laragon/XAMPP) et crée la base de la Ludothèque. Le driver JDBC s'ajoute comme dépendance ; la connexion se configure dans application.properties.

3. L'IDE : IntelliJ IDEA. La version Community suffit ; Ultimate (gratuite pour les étudiants) ajoute le support Spring/JPA. Un client base comme MySQL Workbench ou DBeaver aide à inspecter les tables.

💡 Conseil : crée un vrai projet Spring Boot connecté à MySQL dès la leçon 2, et fais-le grandir leçon après leçon jusqu'à l'application déployée.
