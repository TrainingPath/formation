🛠️ Avant de commencer : l'environnement du projet

1. La pile PHP est déjà installée. PHP 8.5 + Composer (cours PHP), Laravel (cours Laravel), et Node.js + npm pour les assets front (Vite).

2. MySQL. Fourni par Laragon/XAMPP ou via Docker. La connexion se configure dans .env (DB_CONNECTION=mysql) ; les tables se créent par les migrations : php artisan migrate.

3. L'IDE : PhpStorm (+ plugin « Laravel Idea ») ou VS Code + extensions PHP/Laravel. Serveur de développement : php artisan serve.

💡 Conseil : crée un vrai projet Laravel connecté à MySQL dès la leçon 2, et fais-le grandir leçon après leçon jusqu'à l'application déployée.
