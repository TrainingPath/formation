🐳 Conteneurs (Docker)

« Ça marche chez moi » n'est pas une stratégie de déploiement. Les conteneurs emballent une application et tout ce dont elle a besoin pour tourner à l'identique partout : poste de dev, serveur de test, production.

Chaque leçon : théorie · 15 exercices auto-corrigés · 1 exercice final · 1 exercice d'écriture · 1 étape du fil rouge (la Ludothèque du Niveau 6 que l'on conteneurise, morceau par morceau).

Prérequis : le cours Linux (terminal, permissions) et idéalement un capstone du Niveau 6 — les exemples conteneurisent la Ludothèque Python · Django · MySQL, mais tout s'adapte à ta pile.

🧵 Voir le projet complet — La Ludothèque en conteneurs

📝 Mode examen (révision aléatoire) 🎓 Utiliser une IA comme tuteur

🛠️ Avant de commencer : installe ton environnement

1. Docker. Installe Docker Desktop (Windows/macOS) ou Docker Engine (Linux). Sous Windows, il s'appuie sur WSL2. Vérifie : docker --version puis docker run hello-world. Docker Compose est inclus (docker compose version).

2. Un terminal et un éditeur. Tout se pilote en ligne de commande. VS Code + l'extension « Docker » (Microsoft) colore les Dockerfile et docker-compose.yml et gère conteneurs et images depuis l'éditeur.

3. Un registre (optionnel). Docker Hub (gratuit) pour publier et tirer des images ; on peut aussi utiliser le registre de GitHub (ghcr.io), réutilisé au cours CI/CD.

💡 Conseil : installe Docker dès la leçon 2 et tape chaque commande toi-même — les conteneurs s'apprennent au clavier, pas en lisant.
