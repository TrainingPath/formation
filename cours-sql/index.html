🛠️ Avant de commencer : installe ton environnement

1. Un SGBD pour pratiquer. Le plus simple pour débuter : SQLite (aucun serveur, une base = un fichier). Sinon MySQL/MariaDB ou PostgreSQL. Le SQL du cours est standard et fonctionne sur les trois.

2. Un client pour écrire et exécuter les requêtes. DBeaver (gratuit, multi-SGBD) ou DB Browser for SQLite. Sans rien installer, un bac à sable en ligne comme SQLite Online ou DB Fiddle permet de tester immédiatement.

3. Un éditeur pour tes scripts. Garde tes fichiers .sql dans un éditeur de texte (versionnables avec Git) : VS Code + l'extension « SQLTools » ajoute coloration, autocomplétion et exécution directe des requêtes.

💡 Conseil : installe un vrai SGBD (SQLite, MySQL ou PostgreSQL) et exécute chaque requête. Le SQL se comprend en interrogeant de vraies données.
