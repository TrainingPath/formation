🛠️ Avant de commencer : installe ton environnement

1. Le nécessaire : Python (3.14). Télécharge-le depuis python.org et, sous Windows, coche « Add Python to PATH » à l'installation. Vérifie : python --version. Bonne habitude dès le départ : travailler dans un environnement virtuel (python -m venv .venv puis active-le) pour isoler les dépendances de chaque projet.

2. L'IDE recommandé : PyCharm Community Edition (gratuit, JetBrains) — complet et pensé pour Python. Alternative très populaire : VS Code avec l'extension « Python » (Microsoft, qui installe aussi Pylance pour l'autocomplétion et le débogueur). Les deux détectent et utilisent ton environnement virtuel.

3. Ou un simple éditeur de texte. Python est parfait pour débuter sans IDE : il est livré avec IDLE (éditeur minimal intégré), et un éditeur léger comme Notepad++, Sublime Text ou Nano convient très bien — on lance ensuite python fichier.py dans le terminal, ou on teste ligne par ligne dans l'interpréteur interactif (python). L'IDE apporte surtout le confort (autocomplétion, débogueur) quand le code grandit.

💡 Conseil : une leçon par jour, dans l'ordre. Code chaque exemple dans un vrai interpréteur : lire ne suffit pas.
