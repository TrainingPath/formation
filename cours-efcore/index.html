🧿 EF Core (C#)

Entity Framework Core est l'ORM de .NET : le pont entre tes classes C# et tes tables SQL Server. Le cours ASP.NET Core l'a effleuré ; ici on ouvre le capot — DbContext, migrations, relations, LINQ, transactions et performances.

Chaque leçon : théorie · 15 exercices auto-corrigés · 1 exercice final · 1 exercice d'écriture. Le fil conducteur : la couche de persistance de la Ludothèque (Jeu, Membre, Location, Avis), sur le schéma SQL Server conçu au Niveau 4.

Prérequis : ASP.NET Core, SQL et SQL Server. Les équivalents Hibernate/JPA (Java), Eloquent (Laravel) et ORM Django sont signalés au fil des leçons : un ORM appris, tous compris.

🛠️ Avant de commencer : préparer EF Core

1. Le SDK .NET est déjà là. Tu as le .NET SDK 10 (cours C#). EF Core s'ajoute par projet via NuGet (dotnet add package Microsoft.EntityFrameworkCore…). Installe l'outil des migrations : dotnet tool install --global dotnet-ef.

2. Une base et son provider. SQLite (le plus simple pour apprendre), SQL Server ou MySQL : chaque base a son paquet provider NuGet (…Sqlite, …SqlServer, Pomelo.…MySql).

3. L'IDE. Visual Studio 2022, Rider ou VS Code + « C# Dev Kit ». Tout se pilote aussi à la CLI : dotnet ef migrations add … puis dotnet ef database update.

💡 Conseil : crée un vrai projet console ou web branché sur ta base SQL Server du Niveau 4 et active LogTo dès la leçon 2 — voir le SQL que génère chaque ligne de C# est la meilleure façon d'apprendre un ORM.
