🛠️ Avant de commencer : installe ton environnement

1. Le nécessaire : un compilateur. C est un langage compilé : il te faut GCC (ou Clang). Sous Linux : sudo apt install gcc. Sous macOS : xcode-select --install. Sous Windows : installe MinGW-w64 (via MSYS2) ou le WSL. Vérifie : gcc --version. On compile avec gcc prog.c -o prog puis on lance ./prog.

2. L'IDE recommandé : VS Code (gratuit) avec l'extension « C/C++ » (Microsoft) pour l'autocomplétion et le débogueur. Alternatives complètes : Code::Blocks (livré avec un compilateur, idéal pour débuter) ou CLion (JetBrains, gratuit pour les étudiants).

3. Ou un simple éditeur de texte + le terminal. C se prête parfaitement à l'apprentissage « à la main » : un éditeur léger (Nano, Notepad++, Sublime Text), puis gcc dans le terminal. Compile toujours avec les avertissements activés : gcc -Wall -Wextra prog.c -o prog — ils t'évitent la moitié des bugs des débutants.

💡 Conseil : une leçon par jour, dans l'ordre. Compile et exécute chaque exemple : en C, lire ne suffit pas — c'est en corrigeant les erreurs du compilateur qu'on apprend.
