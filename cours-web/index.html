🎨 Le front-end : HTML, CSS, JavaScript

Le front-end, c'est tout ce que l'utilisateur voit et touche : la structure de la page (HTML), son apparence (CSS) et son interactivité (JavaScript). En trois semaines, tu apprends les trois langages du navigateur, dans cet ordre — comme on construit une maison : les murs, la peinture, l'électricité.

Chaque leçon : théorie · 15 exercices auto-corrigés · 1 exercice final · 1 exercice d'écriture. L'exemple fil conducteur : le site de la Ludothèque, construit page après page — la même Ludothèque que tu retrouves dans les projets du Niveau 6.

Prérequis : aucun logiciel exotique, un navigateur et un éditeur de texte suffisent. Le cours Algorithmique aide pour la semaine JavaScript, mais tout est expliqué au fil des leçons.

🛠️ Avant de commencer : installe ton environnement

1. Un navigateur moderne et ses DevTools. Chrome, Firefox ou Edge : l'inspecteur d'éléments, l'onglet Réseau et la console JavaScript sont tes principaux outils. Rien d'autre n'est obligatoire pour le HTML/CSS.

2. L'éditeur recommandé : VS Code (gratuit). Ajoute l'extension « Live Server » (recharge la page à chaque sauvegarde) et « Prettier » (formatage automatique). Alternatives : Sublime Text, Notepad++.

3. Node.js (plus tard, optionnel). Pour la partie JavaScript moderne (fetch, outillage), Node.js + npm servent d'outils. Au début, un simple fichier .html ouvert dans le navigateur suffit — aucun build.

💡 Conseil : crée ton dossier ludotheque/ dès la leçon 1 et tape chaque exemple toi-même — le front-end s'apprend au clavier, avec le navigateur ouvert à côté.
