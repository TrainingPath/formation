🛠️ Avant de commencer : installe ton environnement

1. Le nécessaire : un compilateur C++. g++ (GCC) ou clang++. Sous Linux : sudo apt install g++. Sous macOS : xcode-select --install. Sous Windows : MinGW-w64 (via MSYS2) ou le WSL. On compile en précisant la norme : g++ -std=c++17 -Wall -Wextra prog.cpp -o prog, puis ./prog.

2. L'IDE recommandé : VS Code (gratuit) avec l'extension « C/C++ » (Microsoft). Alternatives complètes : CLion (JetBrains, gratuit pour les étudiants) ou Qt Creator (idéal si tu vises des interfaces graphiques).

3. Compile toujours avec les avertissements et une norme récente : -std=c++17 -Wall -Wextra. Le C++ moderne privilégie la STL et les smart pointers à la gestion mémoire manuelle : on écrit du code plus court et plus sûr.

💡 Conseil : une leçon par jour, dans l'ordre. Compile et exécute chaque exemple — en C++, on apprend en pratiquant.
