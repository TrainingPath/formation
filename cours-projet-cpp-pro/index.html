🛠️ Avant de commencer : la chaîne outillée

1. Git et un compte GitHub. Tout le projet vit dans un dépôt versionné, avec des branches et des pull requests. La CI (GitHub Actions) s'exécute à chaque push.

2. Docker et Docker Compose. Le code C++, le compilateur et MySQL tournent dans des conteneurs reproductibles — « ça marche chez moi » n'existe plus. Vérifie : docker --version.

3. La chaîne de build C++. g++/cmake, MySQL Connector/C++, plus les outils qualité : -fsanitize=address,undefined, un framework de test (GoogleTest/Catch2), un linter (clang-tidy, cppcheck) et un scanner d'image (Trivy). On les câble dès la première leçon, pas à la fin.

💡 Ici, on n'ajoute pas l'outillage après coup : on construit, on industrialise et on sécurise d'un même geste. Une leçon par jour, dans l'ordre.
