🧩 Projet full-stack — La Ludothèque en C

Le capstone « à la main » : réunir le langage C, la conception (Merise), le SQL et MySQL pour construire une application complète, de la base de données à l'interface.

Chaque leçon : théorie · 15 exercices auto-corrigés · 1 exercice final · 1 exercice d'écriture.

Prérequis : le langage C, Merise, SQL et MySQL.

🧵 Découvrir le fil rouge — La Ludothèque

📝 Mode examen (révision aléatoire) 🎓 Utiliser une IA comme tuteur 🚀 Étape finale : publier & faire relire

🛠️ Avant de commencer : l'environnement

1. Le compilateur et make. gcc (ou clang) et make pour automatiser la compilation. Sous Debian/Ubuntu : sudo apt install build-essential.

2. Le serveur MySQL et son connecteur C. Installe MySQL (ou MariaDB) et la bibliothèque de développement du client : sudo apt install mysql-server libmysqlclient-dev (ou libmariadb-dev). On compile alors avec gcc app.c $(mysql_config --cflags --libs) -o app.

3. L'éditeur. VS Code (extension C/C++) ou CLion. Compile toujours avec -Wall -Wextra et teste régulièrement avec valgrind ou -fsanitize=address : en C, la rigueur mémoire fait la fiabilité.

💡 Ce projet assemble les briques déjà vues : rien de neuf à apprendre isolément, tout est de les faire travailler ensemble. Une leçon par jour, dans l'ordre.
