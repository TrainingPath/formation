🗄️ Projet de développement SGBD

Niveau : intermédiaire. Construire une vraie application connectée à une base de données, de A à Z : une bibliothèque avec gestion des ventes et des commissions, développée en Java (JDBC, MVC, DAO, JavaFX).

Chaque jour : théorie illustrée · 15 exercices auto-corrigés · 1 exercice final · une requête ou un code à écrire.

💾 Progression enregistrée dans ce navigateur, sur cet appareil — non synchronisée. Changer d'appareil ou de navigateur, ou vider les données du site, la remet à zéro.

📝 Mode examen (révision aléatoire) 🎓 Utiliser une IA comme tuteur 🚀 Étape finale : publier & faire relire

🛠️ Avant de commencer

Prérequis : les bases de Java (variables, classes, méthodes) et du SQL (le cours « Initiation aux bases de données » suffit). Il te faut le JDK, NetBeans, un serveur MySQL/MariaDB, le driver JDBC MySQL et le SDK JavaFX (tout est gratuit ; l'installation est guidée dans les leçons).

💡 Conseil : tape chaque exemple toi-même. On n'apprend une base de données qu'en la manipulant.
