🗄️ SGBD — SQL avancé & données

Niveau : intermédiaire → avancé. Ce cours reprend là où le cours SQL s'arrête. Le SQL de base sait interroger une base propre ; ici tu apprends à nettoyer, transformer et analyser des données réelles — celles qui arrivent avec des espaces en trop, des NULL, des doublons et des dates en texte.

Au programme : fonctions de chaîne et de date, gestion des NULL et conversions, CASE WHEN, expressions régulières, déduplication, CTE, fonctions de fenêtre, PIVOT, contrôle qualité et performance.

Chaque jour : théorie illustrée · 15 exercices auto-corrigés · 1 exercice final · une requête à écrire.

📝 Mode examen (révision aléatoire) 🎓 Utiliser une IA comme tuteur

🛠️ Prérequis et environnement

Prérequis : le cours SQL (SELECT, WHERE, jointures, GROUP BY). Inutile d'avoir fait MySQL ou SQL Server : ce cours est transversal.

Les fonctions présentées varient d'un SGBD à l'autre. Chaque leçon donne donc la syntaxe standard puis les variantes MySQL / MariaDB, PostgreSQL et SQL Server quand elles diffèrent. Entraîne-toi sur le SGBD de ton choix, ou sur un bac à sable en ligne (DB Fiddle, SQL Fiddle).

💡 Conseil : tape chaque requête au lieu de la lire. Le nettoyage de données s'apprend en se cognant aux cas tordus.
