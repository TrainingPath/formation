🔌 API REST

Une API est le contrat entre ton back-end et le reste du monde : le front-end, une appli mobile, les partenaires. Bien conçue, elle se comprend sans documentation ; mal conçue, elle se traîne pendant des années. Ce cours t'apprend HTTP en profondeur, puis la conception REST propre : ressources, méthodes, codes de statut, erreurs, versions, sécurité.

Chaque leçon : théorie · 15 exercices auto-corrigés · 1 exercice final · 1 exercice d'écriture. Le fil conducteur : concevoir, construire et sécuriser l'API de la Ludothèque — jeux, membres, locations, avis — celle-là même que tes capstones du Niveau 6 exposent. Ce cours t'apprend à la concevoir PROPREMENT.

Prérequis : avoir suivi un framework du Niveau 3 (Spring, Laravel, ASP.NET Core ou Django) est l'idéal — les exemples concrets utilisent Django REST Framework, avec les équivalents des trois autres cités au passage. Les concepts, eux, sont universels.

📝 Mode examen (révision aléatoire) 🎓 Utiliser une IA comme tuteur

🛠️ Avant de commencer : installe ton environnement

1. Un client REST pour tester tes appels. curl (en ligne de commande, partout), Postman ou Insomnia (interfaces graphiques, collections de requêtes réutilisables), ou l'extension « REST Client » de VS Code. Indispensable pour rejouer chaque requête du cours.

2. Le framework de ta pile. Les exemples utilisent Django REST Framework (Python), mais Spring, Laravel ou ASP.NET Core conviennent tout aussi bien — reprends l'environnement du framework suivi au Niveau 3.

3. Un éditeur et de quoi lire le JSON. VS Code (avec l'extension de ton langage) et un formateur JSON (intégré aux DevTools du navigateur ou à Postman) rendent les réponses lisibles.

💡 Conseil : garde un client REST ouvert (curl, Postman ou Insomnia) et rejoue chaque requête toi-même — une API se comprend en la testant.
