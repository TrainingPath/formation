Exemples sous Ubuntu / Debian (apt). Ouvre un vrai terminal et tape tout toi-même.

📝 Mode examen (révision aléatoire) 🎓 Utiliser une IA comme tuteur

🛠️ Avant de commencer : installe ton environnement

1. Accès à un vrai Linux. Sous Windows, le plus simple est WSL2 (wsl --install, distribution Ubuntu). Sinon une machine virtuelle (VirtualBox + Ubuntu), un double-boot, ou un Raspberry Pi. Sur macOS, le terminal est un Unix proche (mais certaines commandes diffèrent).

2. Un terminal, c'est tout. Pas d'IDE : Linux s'apprend au shell. L'accès à une machine distante se fait par SSH (ssh utilisateur@serveur).

3. Un éditeur en console. Apprends au moins les bases de nano (simple) ; Vim est partout et vaut l'investissement. Pour éditer confortablement des fichiers distants, VS Code + l'extension « Remote - SSH » ouvre un dossier distant comme s'il était local.

💡 Conseil : une leçon par jour, dans l'ordre. Le terminal ne s'apprend pas en lisant — il s'apprend en tapant.
