🛠️ Avant de commencer : préparer Spring Boot

1. Le JDK est déjà là. Tu as installé le JDK 25 au cours Java : Spring n'a besoin de rien de plus côté langage. Pas de dépendance à installer globalement — le projet embarque un wrapper (mvnw ou gradlew) qui télécharge Maven/Gradle tout seul.

2. Générer le projet : Spring Initializr. On ne part pas d'une page blanche : va sur start.spring.io, choisis Maven + Java 25, et coche les dépendances de départ : Spring Web, Spring Data JPA, le driver de base (H2 ou MySQL), Validation, Spring Boot DevTools. Télécharge l'archive et ouvre-la dans l'IDE. (IntelliJ propose directement « New Project ▸ Spring Boot » qui fait la même chose.)

3. Régler l'IDE. IntelliJ IDEA Community suffit pour suivre le cours ; la version Ultimate (payante, gratuite pour les étudiants) ajoute le support Spring complet (navigation entre beans, autocomplétion d'application.properties). Sur VS Code, installe le « Spring Boot Extension Pack » (Microsoft/VMware) en plus de l'« Extension Pack for Java ». Un éditeur de texte simple reste possible (on lance ./mvnw spring-boot:run), mais l'IDE est vivement conseillé ici : Spring repose sur beaucoup d'annotations que l'autocomplétion rend bien plus lisibles.

💡 Conseil : une leçon par jour, dans l'ordre. Crée un vrai projet Spring Boot dès la leçon 1 et fais-le grandir tout au long du cours.
