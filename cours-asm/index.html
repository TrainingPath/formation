🛠️ Avant de commencer : l'environnement

1. Assembleur x86-64. Fil principal du cours : NASM (syntaxe Intel). Sous Linux : sudo apt install nasm. On assemble puis on lie : nasm -f elf64 prog.asm -o prog.o && ld prog.o -o prog, puis ./prog. La syntaxe AT&T s'assemble, elle, avec as/gcc (déjà présents avec les binutils).

2. ARM64 (AArch64). Pour tester l'ARM sur une machine x86, on utilise un cross-assembleur (gcc-aarch64-linux-gnu) et l'émulateur QEMU (qemu-aarch64). Sur un Raspberry Pi ou un Mac Apple Silicon, l'ARM64 est natif.

3. Observer le code généré. gcc -S -O0 prog.c produit l'assembleur (AT&T) correspondant à un programme C : un excellent moyen de voir « ce que le C devient » (leçon 18). Un débogueur comme gdb permet de suivre les registres pas à pas.

💡 L'assembleur récompense la patience : chaque instruction fait une chose minuscule. Assemble et exécute chaque exemple, et compare les trois cibles pour comprendre ce qui est universel et ce qui est propre à chaque machine.
