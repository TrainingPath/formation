🏆 Le projet full-stack outillé — La Ludothèque pro (C# · ASP.NET Core)

Le couronnement : reconstruire la Ludothèque comme en entreprise — conteneurisée dès le premier jour, testée et livrée par un pipeline, sécurisée par conception. Non plus « d'abord l'app, puis les outils », mais tout ensemble, du bon geste au bon moment.

Chaque leçon : théorie · 15 exercices auto-corrigés · 1 exercice final · 1 exercice d'écriture · 1 étape du fil rouge (le projet professionnel qui grandit).

Prérequis : le capstone C# · ASP.NET (Niveau 6), et les trois cours d'outillage (Niveau 7) : Docker, CI/CD & Git avancé, Sécurité applicative.

🧵 Voir le projet complet — La Ludothèque pro

📝 Mode examen (révision aléatoire) 🎓 Utiliser une IA comme tuteur 🚀 Étape finale : publier & faire relire

ℹ️ Transparence — sorties non certifiées par exécution. Les sorties attendues des encadrés « À toi de jouer » de ce cours ont été relues avec soin, mais n’ont pas été certifiées par une exécution réelle de C# (l’outil n’était pas disponible au moment de la génération). Les cours Python, SQL, C, C++ et Java, eux, sont vérifiés automatiquement à chaque mise à jour du dépôt. Si ta sortie diffère de celle annoncée alors que ton code te semble juste, fie-toi à ton exécution et compare avec la solution.

🛠️ Avant de commencer : la chaîne outillée

1. Git et un compte GitHub. Projet versionné avec branches, pull requests et CI (GitHub Actions).

2. Docker et Docker Compose. L'application ASP.NET Core et SQL Server (image Linux) tournent en conteneurs reproductibles. Vérifie : docker --version.

3. La chaîne .NET et la qualité. .NET SDK 10, tests xUnit/NUnit, dotnet format et les analyseurs Roslyn, plus un scanner d'image (Trivy). Câblés dès le départ.

💡 Conseil : dès la leçon 1, travaille dans le dépôt Git avec Docker Compose — tout ce cours se fait « à la pro », jamais à la main.
