🛠️ Avant de commencer : installe ton environnement

1. Le nécessaire : le JDK. Java a besoin du JDK (Java Development Kit) pour compiler et exécuter le code. Installe une version LTS courante (JDK 25), par exemple Eclipse Temurin (Adoptium) ou l'OpenJDK de ta distribution. Vérifie ensuite dans un terminal : java -version et javac -version.

2. L'IDE recommandé : IntelliJ IDEA Community Edition (gratuit, JetBrains). Il gère tout pour toi : autocomplétion, compilation, exécution, débogueur, et peut même télécharger un JDK à la création du projet. Alternatives : Eclipse (gratuit) ou VS Code — dans ce dernier, installe l'extension « Extension Pack for Java » (Microsoft), qui ajoute compilation, exécution et débogage.

3. Ou un simple éditeur de texte. Rien n'oblige à utiliser un IDE : un éditeur léger comme Notepad++, Sublime Text, Nano ou Vim suffit, puis on compile et on lance à la main dans un terminal (javac Programme.java puis java Programme). C'est formateur pour comprendre ce que l'IDE fait à ta place — mais pour la suite, l'autocomplétion et le débogueur d'un IDE font gagner beaucoup de temps.
