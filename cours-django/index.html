🛠️ Avant de commencer : préparer Django

1. Ce qu'il faut en plus de Python. Tu as déjà Python (cours Python) et l'habitude des environnements virtuels. Crée-en un pour le projet, active-le, puis installe Django avec pip : python -m venv .venv, active-le, pip install django. C'est tout — Django est « batteries incluses » (serveur de dev, ORM, admin fournis). Les extras viendront par pip au fil des leçons (pip install djangorestframework, etc.), et un requirements.txt figera les versions.

2. Créer le projet. django-admin startproject ludotheque, puis python manage.py runserver pour lancer le serveur de développement. Chaque fonctionnalité vivra dans une « app » créée par python manage.py startapp catalogue.

3. Régler l'IDE. Sur VS Code, l'extension « Python » (déjà installée au cours Python) suffit ; sélectionne l'interpréteur de ton environnement virtuel (barre d'état en bas) pour que l'autocomplétion trouve Django. PyCharm Professional (payant, gratuit pour les étudiants) ajoute un support Django dédié (templates, ORM, gestion des migrations) — la version Community n'a pas ce support. Un simple éditeur de texte reste possible : tout se pilote avec manage.py en ligne de commande.

💡 Conseil : une leçon par jour. Crée un vrai projet, lance python manage.py runserver et regarde ton app vivre.
