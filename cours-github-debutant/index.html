🐙 GitHub — débutant à intermédiaire

Niveau : débutant → intermédiaire. Un mois pour maîtriser Git et la plateforme GitHub : versionner son code, collaborer avec des Pull Requests et des Issues, et publier son travail.

Chaque jour : théorie illustrée · 15 exercices auto-corrigés · 1 exercice final · une manipulation à refaire.

📝 Mode examen (révision aléatoire) 🎓 Utiliser une IA comme tuteur

🛠️ Avant de commencer

Aucun prérequis technique. Il te faut un compte GitHub (gratuit) et Git installé sur ton ordinateur — l'installation est guidée dès les premières leçons. Un terminal suffit ; aucun langage de programmation particulier n'est requis.

💡 Conseil : crée un dépôt de test et refais chaque commande. GitHub s'apprend en cassant et en réparant, sans risque.
