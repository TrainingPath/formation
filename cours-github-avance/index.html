🚀 GitHub — intermédiaire à avancé

Niveau : intermédiaire → avancé. Réécrire l'historique proprement (rebase, cherry-pick), professionnaliser les Pull Requests, et surtout automatiser build, tests et déploiement avec GitHub Actions (CI/CD).

Chaque jour : théorie illustrée · 15 exercices auto-corrigés · 1 exercice final · une manipulation à refaire.

💾 Progression enregistrée dans ce navigateur, sur cet appareil — non synchronisée. Changer d'appareil ou de navigateur, ou vider les données du site, la remet à zéro.

📝 Mode examen (révision aléatoire) 🎓 Utiliser une IA comme tuteur

🛠️ Avant de commencer

Prérequis : maîtriser les bases de Git et GitHub (commits, branches, merge, Pull Requests) — le cours « GitHub débutant à intermédiaire » suffit. Un compte GitHub et Git installés. Le CLI gh est utilisé en fin de parcours (installation guidée).

💡 Conseil : crée un dépôt de test et refais chaque commande. GitHub s'apprend en cassant et en réparant, sans risque.
