🟣 Projet de développement SGBD — C#

Niveau : intermédiaire. Le même projet que la version Java, mais en C# avec Visual Studio : une bibliothèque avec ventes et commissions, connectée à une base via ADO.NET, jusqu\'à une application Windows Forms complète.

Sécurité (injections SQL, validation regex), connexion et requêtes paramétrées, architecture MVC et Repository, transactions, puis l\'interface graphique.

Chaque jour : théorie illustrée · 15 exercices auto-corrigés · 1 exercice final · du code à écrire.

📝 Mode examen (révision aléatoire) 🎓 Utiliser une IA comme tuteur

🛠️ Prérequis et environnement

Prérequis : les bases de C# et du SQL (le cours « Initiation aux bases de données » suffit). Il te faut Visual Studio (édition Community gratuite) avec la charge de travail .NET Desktop, un serveur MySQL/MariaDB (ou SQL Server), et le connecteur ADO.NET (paquet NuGet MySqlConnector pour MySQL, ou Microsoft.Data.SqlClient pour SQL Server).

💡 Conseil : tape chaque exemple dans Visual Studio. On apprend en compilant et en corrigeant les erreurs.
