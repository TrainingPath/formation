🛠️ Avant de commencer : installe ton environnement

1. Le nécessaire : PHP (8.5). Le plus simple sous Windows est un paquet tout-en-un comme Laragon ou XAMPP, qui fournit d'un coup PHP, un serveur web (Apache) et MySQL — pratique pour les leçons sur les bases de données. Sur macOS/Linux, PHP s'installe via le gestionnaire de paquets (brew install php, apt install php). Vérifie : php -v. Pour les leçons, le serveur intégré suffit : php -S localhost:8000.

2. L'IDE recommandé : PhpStorm (JetBrains, payant mais gratuit pour les étudiants) — le plus complet pour PHP. Alternative gratuite : VS Code avec l'extension « PHP Intelephense » (autocomplétion, navigation) et, si tu veux déboguer, « PHP Debug » (avec Xdebug).

3. Ou un simple éditeur de texte. PHP se prête très bien à un éditeur léger — Notepad++, Sublime Text, Nano — puisqu'il n'y a rien à compiler : on écrit le fichier, on lance php fichier.php ou le serveur intégré, et on rafraîchit le navigateur. C'est d'ailleurs ainsi que beaucoup ont appris PHP ; l'IDE devient utile quand le projet grossit (autocomplétion, refactoring).

💡 Conseil : une leçon par jour, dans l'ordre. Code chaque exemple dans un vrai éditeur : lire ne suffit pas.
