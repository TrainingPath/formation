🌱 Git — les bases

Sans contrôle de version, un projet vit dans la peur : projet_final_v2_VRAIMENT_final.zip. Git enregistre l'histoire complète de ton projet, te laisse revenir en arrière sans rien perdre et prépare le travail en équipe.

Chaque leçon : théorie · 15 exercices auto-corrigés · 1 exercice final · 1 exercice d'écriture. L'exemple fil conducteur : le carnet de recettes, un petit projet que l'on versionne de la première ligne au dépôt en ligne.

Prérequis : savoir ouvrir un terminal (le cours Linux aide, mais tout est rappelé). Ce cours donne exactement les bases attendues par le cours CI/CD & Git avancé du Niveau 7.

📝 Mode examen (révision aléatoire) 🎓 Utiliser une IA comme tuteur

🛠️ Avant de commencer : installe ton environnement

1. Le nécessaire : Git. Installe-le depuis git-scm.com (inclut Git Bash sous Windows). Configure ton identité : git config --global user.name "…" et user.email. Vérifie : git --version.

2. Un terminal et un compte GitHub. Git s'utilise surtout en ligne de commande. Crée un compte gratuit sur github.com pour la partie « dépôt en ligne » ; une clé SSH facilite les push.

3. Client graphique (optionnel) et éditeur. GitHub Desktop, GitKraken ou l'intégration Git de VS Code visualisent l'historique. Un simple éditeur de texte suffit pour les messages de commit (règle-le : git config --global core.editor …). L'essentiel est de taper les commandes toi-même.

💡 Conseil : crée le dépôt du carnet de recettes dès la leçon 2 et tape chaque commande toi-même — Git s'apprend au clavier.
