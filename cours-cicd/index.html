🔁 CI/CD & Git avancé

Au Niveau 6 tu as construit la Ludothèque ; au cours Docker tu l'as conteneurisée — à la main. Ici, on automatise : branches et pull requests pour collaborer, puis un pipeline qui teste, construit, publie et déploie à chaque commit.

Chaque leçon : théorie · 15 exercices auto-corrigés · 1 exercice final · 1 exercice d'écriture · 1 étape du fil rouge (la livraison de la Ludothèque, automatisée morceau par morceau).

Prérequis : les bases de Git (commit, tag), le cours Docker, et un capstone du Niveau 6 — les exemples automatisent la Ludothèque Python · Django · MySQL avec GitHub Actions, mais tout s'adapte.

🛠️ Avant de commencer : installe ton environnement

1. Git et un compte GitHub. Le cours s'appuie sur GitHub Actions : un dépôt sur github.com suffit, la CI tourne côté GitHub (rien à héberger). Reprends ton Git du Niveau 7.

2. Docker (déjà installé). Les pipelines construisent et publient des images : on réutilise l'environnement Docker du cours précédent.

3. Un éditeur avec support YAML. Les workflows sont des fichiers .github/workflows/*.yml : VS Code + l'extension « GitHub Actions » (autocomplétion, validation). Pour tester un workflow en local avant de pousser, l'outil act (optionnel) exécute les Actions sur ta machine via Docker.

💡 Conseil : crée un dépôt GitHub avec ton capstone dès la leçon 4 — chaque pipeline de ce cours peut tourner pour de vrai, gratuitement.
