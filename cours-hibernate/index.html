🐻 Hibernate / JPA (Java)

Tes objets Java vivent en mémoire, tes données vivent dans des tables MySQL : l'ORM fait le pont entre les deux. Dans le cours Spring, Spring Data JPA te cachait cette machinerie derrière des repositories magiques — ici, on ouvre le capot et on la maîtrise.

Chaque leçon : théorie · 15 exercices auto-corrigés · 1 exercice final · 1 exercice d'écriture. Le fil conducteur : construire la couche de persistance de la Ludothèque (jeux, membres, locations, avis) sur le schéma MySQL conçu au Niveau 4.

Prérequis : le cours Spring (Java, Maven, injection), le cours SQL et le cours MySQL du Niveau 4. Ce cours prépare directement le projet full-stack du Niveau 6.

💾 Progression enregistrée dans ce navigateur, sur cet appareil — non synchronisée. Changer d'appareil ou de navigateur, ou vider les données du site, la remet à zéro.

📝 Mode examen (révision aléatoire) 🎓 Utiliser une IA comme tuteur

🛠️ Avant de commencer : préparer Hibernate / JPA

1. Le JDK est déjà là. Tu as le JDK 25 (cours Java). Hibernate/JPA s'ajoute comme dépendance du projet via Maven ou Gradle — rien à installer globalement.

2. Une base de données. Pour apprendre, H2 (en mémoire, zéro configuration) est idéal ; pour du concret, MySQL/MariaDB. Le driver JDBC correspondant s'ajoute lui aussi par dépendance.

3. L'IDE. IntelliJ IDEA (Community suffit) ou Eclipse ; la version Ultimate d'IntelliJ (gratuite pour les étudiants) ajoute un support JPA dédié (visualisation des entités, requêtes JPQL). VS Code + « Extension Pack for Java » reste possible.

💡 Conseil : crée un vrai projet Maven branché sur ta base MySQL de la Ludothèque du Niveau 4, et active show_sql dès la leçon 2 — lire le SQL que Hibernate génère à ta place est la meilleure façon de comprendre (et de vérifier) ce qu'il fait.
