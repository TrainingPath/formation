🎻 Eloquent (PHP)

Eloquent, c'est l'ORM de Laravel : le pont entre tes modèles PHP et tes tables MySQL, avec l'élégance du pattern Active Record. Fini le SQL copié-collé dans tous les contrôleurs — tes objets savent se sauvegarder, se relier et se requêter eux-mêmes.

Chaque leçon : théorie · 15 exercices auto-corrigés · 1 exercice final · 1 exercice d'écriture. Le fil conducteur : la couche de persistance de la Ludothèque (jeux, membres, locations, avis), bâtie sur le schéma MySQL conçu au Niveau 4.

Prérequis : le cours Laravel (qui a effleuré Eloquent), SQL et MySQL. Ici, on maîtrise l'ORM à fond — la clé du projet full-stack du Niveau 6. Les équivalents Hibernate/JPA, EF Core et ORM Django sont signalés au passage.

📝 Mode examen (révision aléatoire) 🎓 Utiliser une IA comme tuteur

🛠️ Avant de commencer : préparer Eloquent

1. PHP et Composer, déjà en place. Tu as PHP 8.5 (cours PHP) ; Eloquent vit dans Laravel, installé avec Composer (cours Laravel). Rien de neuf côté langage.

2. Une base de données. MySQL/MariaDB (fourni par Laragon/XAMPP) ou, pour aller vite, SQLite (un simple fichier : DB_CONNECTION=sqlite dans .env). Les extensions PHP pdo_mysql/pdo_sqlite doivent être activées.

3. L'IDE et Artisan. PhpStorm (excellent support Eloquent) ou VS Code + extensions PHP/Laravel. Les migrations et l'exploration se pilotent en ligne de commande : php artisan migrate, php artisan tinker.

💡 Conseil : travaille dans un vrai projet Laravel branché sur ta base MySQL de la Ludothèque (Niveau 4) — dès la leçon 2, ouvre php artisan tinker pour tester chaque méthode, et active DB::listen pour voir le SQL que génère chacune de tes lignes Eloquent.
