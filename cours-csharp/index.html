🛠️ Avant de commencer : installe ton environnement

1. Le nécessaire : le SDK .NET. C# se compile et s'exécute avec le .NET SDK. Installe la version LTS (.NET 10) depuis dotnet.microsoft.com. Vérifie ensuite dans un terminal : dotnet --version.

2. L'IDE recommandé : Visual Studio 2022 Community (gratuit, Windows). À l'installation, coche la charge de travail « Développement .NET Desktop » (elle inclut le SDK). C'est l'expérience la plus complète : projet, exécution, débogueur, IntelliSense. Alternatives multi-plateformes : JetBrains Rider (gratuit pour usage non commercial) ou VS Code — dans ce dernier, installe l'extension « C# Dev Kit » (Microsoft).

3. Ou un simple éditeur de texte. Un éditeur léger comme Notepad++, Sublime Text ou Vim suffit, avec le SDK et le terminal : dotnet new console pour créer un projet, dotnet run pour l'exécuter. Utile pour comprendre les rouages — mais l'IntelliSense et le débogueur d'un IDE accélèrent nettement le travail par la suite.

💡 Conseil : une leçon par jour, dans l'ordre. Code chaque exemple dans un vrai éditeur : lire ne suffit pas.
