🧩 Le projet full-stack — La Ludothèque (C# · ASP.NET Core · SQL Server)

Le grand assemblage : réunir le langage, le framework et la base de données pour construire l'application complète de la Ludothèque, de la conception au déploiement.

Chaque leçon : théorie · 15 exercices auto-corrigés · 1 exercice final · 1 exercice d'écriture · 1 étape du fil rouge (l'application qui grandit).

Prérequis : les cours C#, ASP.NET Core, Merise et SQL Server. Ici, on ne réapprend pas chaque brique — on les fait travailler ensemble.

🛠️ Avant de commencer : l'environnement du projet

1. La pile .NET est déjà installée. .NET SDK 10 (cours C#) et ASP.NET Core inclus (cours .NET). On crée le projet avec dotnet new webapi (ou mvc) ; EF Core + dotnet-ef gèrent la base.

2. La base : SQL Server. Édition Developer/Express, ou image Docker sur macOS/Linux. Provider EF Core Microsoft.EntityFrameworkCore.SqlServer. Client : SSMS ou Azure Data Studio.

3. L'IDE : Visual Studio 2022 (charge de travail « Développement web et ASP.NET »), ou Rider / VS Code + « C# Dev Kit ».

💡 Conseil : crée un vrai projet ASP.NET Core connecté à SQL Server dès la leçon 2, et fais-le grandir leçon après leçon jusqu'à l'application déployée.
