🧪 Tests & qualité logicielle

Un code sans tests est un code qu'on a peur de toucher : chaque modification devient un pari. Ce cours t'apprend à écrire des tests qui prouvent que ton code fait ce qu'il promet — et qui te donnent le courage de le faire évoluer.

Chaque leçon : théorie · 15 exercices auto-corrigés · 1 exercice final · 1 exercice d'écriture. Le fil conducteur : tester la Ludothèque, l'application de location et vente de jeux du Niveau 6. Les exemples sont en Python / pytest, avec les équivalents JUnit (Java), xUnit (C#) et PHPUnit (PHP) mentionnés au passage : les idées sont les mêmes partout.

Prérequis : un langage du Niveau 2 (idéalement Python) et, dans l'idéal, un capstone du Niveau 6 comme la Ludothèque. Ce cours prépare directement les leçons « le job de tests » et « lint, format, couverture » du cours CI/CD & Git avancé : c'est ici qu'on apprend à écrire les tests que la CI exécutera.

🛠️ Avant de commencer : installe ton environnement

1. L'environnement de ton langage. Les tests se lancent avec l'outillage de ta pile : JUnit (Java, via Maven/Gradle), pytest (Python), PHPUnit (PHP, via Composer), xUnit/NUnit (.NET). Installe celui de la pile que tu suis — les concepts sont identiques partout.

2. Un IDE aide beaucoup. IntelliJ, Visual Studio, PyCharm ou VS Code (avec l'extension de test de ton langage) savent lancer un test d'un clic, afficher le vert/rouge et sauter à l'assertion qui casse.

3. Couverture et lint. Un outil de couverture (JaCoCo, coverage.py, Coverlet, PHPUnit --coverage) montre le code non testé ; un linter (Checkstyle, Ruff/flake8, PHP_CodeSniffer, l'analyseur .NET) attrape les défauts. On les branchera dans la CI (Niveau 7).

💡 Conseil : ouvre un terminal à côté de chaque leçon et fais tourner pytest toi-même — un test, ça s'écrit au clavier, pas en lisant.
