💻 Programmation

De la logique algorithmique au déploiement sécurisé d'une application complète.

Choisis ton langage dans la barre de gauche : chaque parcours contient toutes les formations de sa pile, dans l'ordre conseillé.

🗺️ Parcours conseillé

Quel que soit le langage choisi dans la barre de gauche, chaque parcours suit les mêmes huit étapes, avec un fil rouge commun à partir de l'étape 4 : la Ludothèque, une application de location et de vente de jeux construite morceau par morceau jusqu'au déploiement professionnel. 1. L'algorithmique d'abord — c'est le socle, commun à tous les parcours : tous les langages réutilisent ses exemples (la caisse du cinéma, le ticket de caisse…). 2. Le langage et le front-end — Java ou C# pour les applications, PHP pour le web, Python pour la polyvalence ; le front-end (HTML, CSS, JavaScript) se suit en parallèle ou juste après. 3. Le framework et l'API — Spring après Java, Laravel après PHP, ASP.NET Core après C#, Django après Python, plus la conception d'API REST, transversale aux quatre. 4. Les bases de données — la conception avec Merise, le langage SQL, puis le SGBD de ta pile (SQL Server pour C#, MySQL pour les autres). 5. L'ORM — le pont entre les objets du framework et les tables de la base : Hibernate/JPA, EF Core, Eloquent ou l'ORM de Django selon ta pile. 6. Le projet full-stack — la Ludothèque complète, de la conception au déploiement… mais à la main, sans outillage. 7. L'outillage professionnel — Git, tests & qualité, conteneurs (Docker), CI/CD et sécurité applicative : les outils transverses des équipes, appliqués à ton projet. 8. Le projet full-stack outillé — le couronnement : reconstruire le projet en intégrant dès le premier commit tout l'outillage — construire, industrialiser, sécuriser, d'un même pas. Partout, les exercices d'écriture apparaissent en fin de leçon, là où la notion vient d'être vue : essaie sans aide, utilise les 3 niveaux d'indices, puis regarde la solution commentée.

💡 Besoin de maîtriser l'environnement des serveurs ? Le cours Linux se trouve dans la catégorie Système d'exploitation.
