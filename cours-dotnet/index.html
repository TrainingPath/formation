🛠️ Avant de commencer : préparer ASP.NET Core

1. Le SDK est déjà là. Tu as installé le .NET SDK 10 au cours C# : ASP.NET Core en fait partie, rien à installer de plus côté framework. Un outil global est toutefois utile pour les migrations de base : dotnet tool install --global dotnet-ef. Les dépendances (EF Core, provider MySQL/SQL Server, etc.) s'ajoutent par projet via NuGet — dotnet add package … — pas d'installation globale.

2. Créer le projet. En ligne de commande : dotnet new webapi (API), dotnet new mvc (avec vues Razor) ou dotnet new web (minimal), puis dotnet run. Dans Visual Studio, « Nouveau projet ▸ ASP.NET Core » fait la même chose avec un assistant.

3. Régler l'IDE. Dans Visual Studio 2022, ajoute la charge de travail « Développement web et ASP.NET » (via Visual Studio Installer) : elle apporte les modèles de projet, le débogueur web et les outils de scaffolding. Alternatives : JetBrains Rider ou VS Code + « C# Dev Kit ». Un simple éditeur de texte reste possible (tout se pilote avec la CLI dotnet), mais l'IntelliSense sur l'injection de dépendances et EF Core rend le framework bien plus confortable dans un IDE.

💡 Conseil : une leçon par jour, dans l'ordre. Crée un vrai projet ASP.NET Core dès la leçon 1 et fais-le grandir tout au long du cours.
