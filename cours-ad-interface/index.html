🛠️ Ton laboratoire de test

Ce cours s'appuie sur les consoles graphiques de Windows Server : Gestionnaire de serveur, Utilisateurs et ordinateurs Active Directory (ADUC), Centre d'administration Active Directory (ADAC) et Gestion des stratégies de groupe (GPMC). Aucune ligne de commande n'est nécessaire.

Ne t'entraîne JAMAIS sur un domaine de production. Monte un petit labo isolé (machine virtuelle) avec Windows Server (l'édition d'évaluation gratuite convient) sous Hyper-V, VirtualBox ou VMware. Tu pourras tout casser sans risque et recommencer.

💡 Conseil : un jour à la fois, dans l'ordre. Ne te contente pas de lire — refais chaque manipulation dans ton labo, c'est le geste qui ancre le savoir.
