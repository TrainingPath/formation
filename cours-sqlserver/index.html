🛠️ Avant de commencer : installe ton environnement

1. Microsoft SQL Server. Éditions gratuites : Developer ou Express (microsoft.com). Sur macOS/Linux, passe par l'image Docker officielle (mcr.microsoft.com/mssql/server). Vérifie la connexion avec un client.

2. Un client. SSMS (SQL Server Management Studio, Windows, gratuit) reste la référence ; Azure Data Studio est multi-plateforme et gratuit. En ligne de commande : sqlcmd.

3. Un éditeur pour les scripts. VS Code + l'extension « SQL Server (mssql) » (Microsoft) permet de se connecter à l'instance et d'exécuter du T-SQL directement depuis l'éditeur.

💡 Conseil : installe SQL Server Express (gratuit) et SSMS, et exécute chaque script T-SQL. Le T-SQL se comprend en le lançant.
